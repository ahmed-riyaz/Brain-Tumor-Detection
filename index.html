🎯 Overview

Binary classification of brain MRI images using deep learning

This project implements a deep learning pipeline using transfer learning with the VGG16 architecture to classify MRI brain images as either Tumor or Normal. The model leverages pretrained ImageNet weights and is fine-tuned on a publicly available Kaggle dataset of brain MRI images.

Interpretation

  • ✅ 100% tumor recall — The model never misses a tumor case (0 false negatives), which is critical in medical diagnosis.
  • ⚠️ High false positive rate — 18 out of 20 normal cases are classified as tumor, reducing specificity.
  • 📊 Class imbalance effect — With 124 tumor vs 78 normal training images, the model is biased toward predicting tumor.
  • 🏥 Clinical relevance — In medical screening, high sensitivity (recall) is preferred over specificity — missing a tumor is more dangerous than a false alarm.

💭 Challenges & Learnings

Key challenges encountered and insights gained

Challenges

1. Dataset Acquisition & Format
The Kaggle dataset uses yes/no folder naming instead of tumor/normal, requiring careful remapping during preprocessing.
2. Computational Resources
VGG16's 138M parameters make training expensive without a GPU. Transfer learning with pretrained weights was essential to make training feasible.
3. Overfitting on Small Dataset
With only 253 images, the model tends to memorize training data. Data augmentation and pretrained weights help but can't fully prevent overfitting.
4. Class Imbalance
155 tumor vs 98 normal images causes bias toward predicting tumor, resulting in high recall but low specificity for normal cases.
5. Hyperparameter Sensitivity
Learning rate and epoch count significantly impact performance. Systematic experimentation was necessary to find the best configuration.

Key Takeaways

  • Transfer learning is essential for medical imaging with limited data
  • VGG16's pretrained features work surprisingly well on MRI data despite being trained on natural images
  • In medical contexts, recall (sensitivity) is often more important than precision
  • A confusion matrix provides far more diagnostic insight than accuracy alone
  • Hyperparameter tuning meaningfully impacts model behavior and performance
